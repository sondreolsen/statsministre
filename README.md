# Statsministre

Interaktiv nettside med Europakart som viser land, hovedsteder og dagens politiske ledere.

## Innhold

- Interaktivt kart over europeiske land
- Flaggmarkorer over hovedstedene
- Hover-visning med leder, hovedstad og sittetid
- Søkbar oversikt over land og ledere

## Lokal bruk

Åpne `index.html` i en nettleser.

## Publisering

Repoet er satt opp for GitHub Pages via GitHub Actions. Ved push til `main` blir nettsiden publisert automatisk.
